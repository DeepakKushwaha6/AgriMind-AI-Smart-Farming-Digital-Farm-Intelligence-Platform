Why am I seeing scraped or free data?

AgriMind AI is engineered with a KeyResolver fallback chain so the application never breaks or displays fake data when an API key is missing:

  1. Your API Key (BYOK): When you configure a private key in Settings > API Keys, the system uses it with priority.
  2. Server Shared Key: Used if configured by admin and within quota.
  3. Free Keyless APIs: Open-Meteo, NASA POWER, ISRIC SoilGrids, and Nominatim.
  4. Polite Web Scraping: Automated scheduled scraper that visits public commodity/weather tables with robots.txt compliance and rate limiting.
  5. Cached Snapshot: Used on network failures, clearly stamped with its age and marked as stale.
